How to Complete Your Tasks & Submit Pull Requests

Follow these simple steps to solve assigned issues, avoid common Git errors, and earn verified Proof of Work on your GitHub profile.

📂 Open Your Batch Repository & View Issues
Find your assigned issue labeled with your GitHub username
1
Open Your Assigned Issue & Note the Number
Go to your assigned repository, click the "Issues" tab, and click on the issue assigned to your GitHub username (e.g. Issue #5: Build Navigation Bar). Note down the issue number.
2
Edit the Target File on GitHub Web
Navigate to the file mentioned in your issue description (e.g. src/components/Navbar.js), click the ✏️ (Edit) pencil icon on GitHub web, and write your solution.
3
Commit to a New Branch
Scroll to the bottom of the editor. Select "Create a new branch for this commit and start a pull request". Give it a name like fix/issue-5-solution.
4
Submit PR with Closing Keyword
In the Pull Request title and description, write Closes #5 (replace 5 with your issue number). Click "Create Pull Request". Done! 🎉
1
Clone Repository & Open in VS Code
Open your terminal or command prompt and clone your batch repository:
git clone <repo-url>
cd <repo-folder>
code .
2
Create a Feature Branch
Always create a new branch from main before writing code:
git checkout -b fix/issue-5-solution
3
Develop & Test Your Changes in VS Code
Open the repository in VS Code (code .), edit the target files, and test your changes locally.
4
Stage, Commit & Push to GitHub
Commit your work with a clear message and push your feature branch:
git add .
git commit -m "feat: complete task - solve issue #5"
git push origin fix/issue-5-solution
5
Open Pull Request on GitHub
Click the "Compare & pull request" banner on GitHub and include Closes #5 in your description.
